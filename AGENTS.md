# Project agent workflow

- Use agents only for complex work that can be split into independent parts. Do straightforward edits directly.
- Before delegating, check what is already complete. Assign each agent a distinct scope and files; avoid duplicate research, builds, and overlapping edits.
- Ask for concise findings and only the evidence needed to act. Reuse existing results and build outputs.
- The assistant and its agents are tools used for this assignment; do not describe Codex as owned by the project or user. Preserve the original ZIP and work in the improved copy.
- A single integration owner reviews changes, runs the final relevant builds once, and reports untested dependencies clearly.
